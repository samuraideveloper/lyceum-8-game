# MARK & POLINA: SCHOOL DAY

### MADE BY SAMURAI

Шуточная 3D-игра про школьный день с погонями. Работает прямо в браузере на ПК, iPhone и Android.

Вся игра — это один файл `index.html`. Никакого `npm install`, Node.js, сборки или локального сервера не нужно.

## Публикация на GitHub Pages

1. Создай на GitHub новый публичный репозиторий (например, `school-day`).
2. Нажми **Add file → Upload files** и загрузи `index.html` и `README.md` в корень репозитория.
3. Нажми **Commit changes**.
4. Открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** и нажми **Save**.
6. Через 1–2 минуты игра будет доступна по ссылке `https://ТВОЙ_ЛОГИН.github.io/school-day/`.

Этой ссылкой можно делиться — игра запускается сразу.

## Что нужно для работы

- Современный браузер с WebGL (Chrome, Safari, Firefox, Edge).
- Интернет: библиотека Three.js и шрифты загружаются с CDN.

## Управление

**ПК**

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь | камера (кликни по экрану, чтобы захватить курсор) |
| E | взаимодействие |
| Shift | бег |
| Esc | пауза |
| 1–4 | выбор ответа в диалоге |

**Телефон**

- Джойстик слева — движение.
- Свайпы по правой части экрана — камера.
- Кнопки: **БЕГ** (переключатель), **E** (действие), **II** (пауза).
- Удобнее играть в горизонтальной ориентации.

## Режимы

**Полина (основной).** Собраться дома, дойти до школы, сдать куртку, отсидеть урок, пообедать и вернуться домой. Марк ходит следом и заводит разговоры. Ответы Полины повышают его шкалу раздражения; на максимуме начинается погоня. Можно убегать, менять этаж, прятаться в шкафах и туалетных кабинках. Если Марк теряет Полину надолго — погоня заканчивается.

**Марк (альтернативный).** За 8 минут найти в школе три подарка (булочка, цветок, валентинка), трижды догнать убегающую Полину и вручить их.

**Выходы из школы.** После начала уроков главный вход запирают — ключ лежит в учительской на 2 этаже. Запасной выход в восточном конце коридора 1 этажа открыт всегда.

У каждого режима своя концовка и финальные титры.

## Настройки

Качество графики, тени, дальность прорисовки, громкость и чувствительность камеры. Сохраняются в браузере автоматически. Там же можно снова открыть дисклеймер.
